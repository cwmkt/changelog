
# Changelog - White Label v4.7.0

### ✨ Novas Funcionalidades (Added)

- Swagger na API Acesse dominio/swagger/index.html
- Opção para editar mensagens
- Adição de filtro para filtrar por admin ou nome
- Caixas de entrada verticais, permitindo transferir conversas entre elas
- Idioma Francês adicionado
- Barra lateral para gerenciamento de múltiplas contas

### 🚸 Ajustes e Alterações (Changed)

- Botão de mensagem única exibindo apenas as configurações do WhatsApp
- Exibição do nome do contato no canal Instagram
- Correção da tradução do balão exibido no site fora do horário de atendimento
- Remoção do menu Kanban quando não estiver liberado no Super Admin
- Correção de erro ao agendar vídeos no Agendador
- Nova opção para exibir ou ocultar o nome do agente na API Oficial
- Correção de bug de usuário na Aplicação Anônima
- Melhorias gerais de tradução em toda a aplicação
